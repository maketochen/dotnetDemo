# 复习区 · 作答备份

这里存放大C 前三课的作答备份（`.txt` 格式，避免被 `Solutions.csproj` 编译）。

## 用途

按 `PLAN.md` 的复习机制，第四课完成后会触发**第一次无提示复习**：

1. 小d 把 `Lesson01/02/03` 的 `Exercise.cs` 还原成空白 TODO；
2. 大C **不看 Demo、不看这里的备份**，凭记忆重写一遍；
3. 跑 `dotnet run` 自检，全绿才算过；
4. 卡住了再来这里对照当初的写法，看是哪里没记住。

## 文件

- `Lesson1_作答备份.txt` —— 第一课：变量 / 控制流 / 方法 / 类
- `Lesson2_作答备份.txt` —— 第二课：集合与 LINQ
- `Lesson3_作答备份.txt` —— 第三课：异常与可空类型

## 为什么是 .txt

`Solutions.csproj` 会把目录下所有 `.cs` 编进项目，备份里的 `Exercise` 类会和正式文件冲突。用 `.txt` 保留内容但不参与编译。要看内容直接用文本编辑器打开即可。
