# 参考答案库（做完练习再看）

这里保存的是第一课和第二课的**完整示例代码**，已经写好答案、可以直接运行。

## 怎么用

1. 先在 `Lesson01_Fundamentals` 或 `Lesson02_CollectionsAndLinq` 里自己写 `Exercise.cs`。
2. 卡住了、或者做完想对照标准写法，再来这里看：
   - `Program.cs` —— 第一课全部示例（变量、类型、控制流、方法、类、对象）
   - `Lesson2_Collections.cs` —— 第二课 LINQ 全部示例（Where、Select、排序、聚合）

## 为什么单独放

课程文件夹里只放「讲解 + 你的练习」，保持干净；答案集中在这里，避免你写代码时一眼瞥到答案。
